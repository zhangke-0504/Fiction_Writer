## Why

作者需要一个不开启 AI 也能完成日常写作的本地编辑器，同时希望 Agent 在同一套文件上协作，且不因关闭侧栏或离开作品而中断。V1 用 Markdown 保持作品可阅读、可迁移，把可独立运行的通用 Harness 与小说写作规则分开。

## What Changes

- 提供个人书库、创建小说弹窗和小说工作区。小说名、简介必填，题材、文风选填；书库按书名和已有作者信息模糊检索。工作区包含基本信息、人物／物品／场景、伏笔、全书大纲和章节；点击章节直接编辑 Markdown 正文。书籍、主体、伏笔、章节和 Session 删除均为硬删除，不设归档或删除确认弹窗。
- 通过 `Ctrl+Alt+I` 或面板按钮打开 Harness。Session 历史只在其中展示；会话可绑定小说或用户指定的普通目录，支持选择模型、默认 `high` 的思考等级、附加文件、停止任务及删除会话。任务由后台持有，切页不打断；编辑器分别接收已落盘的变更和当前章未落盘的生成预览。
- 设置页可新增、编辑和选择多条模型配置：名称、API Key、请求地址、手填的单个模型 ID，折叠高级区支持 Chat Completions、Responses、Anthropic Messages。优先用 DeepSeek 验证真实的流式工具往返，不将任意兼容端点视为等价。
- 提供不依赖小说结构的搜索、文件读写与命令执行工具，以及小说上下文、关联修改和流式写章工具。内置 Skills 覆盖故事一致性、单章生成与续写、一键生成全书；整书按阶段运行并记录进度。
- V1 不做「其他」书库或导入、出版／定稿／修订版本、团队协作、用量统计、模型列表发现、代理拦截、外部 MCP 服务集成、工具沙箱或逐步审批，也不承诺应用完全退出后继续执行。

## Capabilities

### New Capabilities

- `markdown-novel-workspace`: 个人书库、小说信息和资产编辑、章节正文、文件持久化与引用完整性。
- `background-agent-harness`: 模型配置与协议适配、通用工具、后台会话、订阅、取消和编辑器实时同步。
- `novel-writing-workflows`: 跨资产一致性检查、单章生成和续写、可继续的分阶段整书生成。

## Impact

- 新增 Windows 优先的桌面外壳、编辑界面、本地后台运行器、模型适配器、工具注册与写作任务模块；不迁移现有应用或数据库。
- 作品保存在 `.md` 文件中；模型配置、Session 历史及工作流进度是独立的应用数据。设置与开发测试用的凭据不得进入 Git、作品或模型工具参数。
