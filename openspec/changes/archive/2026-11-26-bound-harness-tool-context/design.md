## Context

[提案](./proposal.md)针对主 Agent 登记范围前的长取材链。长稿中已观测到标准档 8,192 的明确输出触限，不能把本地输入估算当作供应商实际消耗或根因。已有范围时的 Messages 小步续接，以及整书正文请求的选档交接，分别已有独立回归；一期不重做这两条路径。

目前 `book_get_context` 已有目录索引和原文 `offset/length`，但指定文档后省略 `length` 会读至多 44,000 个字符，显式 `length` 的上限却是 6,000。无文档查询还可能回传多份资料全文。通用 `search_text` 的路径、行号和截短预览不提供书内修订与原文字段范围。`ActiveContext.fit` 在请求已经过大时才收缩工具历史；单条大小保护也不能约束同一次回复调用多次读取或多轮累积的体积。

此变更实现为 Worker 内现有单主 Agent 的工具与出站装配改进。普通目录工具、写作专用生成请求、同会话旧聊天原文配额、写入事务和模型能力选档都沿用现状。

## Goals / Non-Goals

**Goals:**

- 默认轻量定位，按真实文档及修订回读小段原文；需要完整资料时仍能通过明确请求分批取得，不凭摘要写稿。
- 让可重读资料在单条、单轮和跨轮均有独立于模型硬窗口的预算；保留本轮作者要求、协议配对、活动状态和真实回执。
- 在实际出站请求上验证分页、预算、已读及诊断语义，用长稿对照区分输入减负、输出触限与业务完成。

**Non-Goals:**

- 不引入子代理、通用委派、并发调度、后台猜章、自动召回、额外模型摘要请求或新的写作流程。二期独立推进。
- 不新增产品配置、审批、MCP 校验关卡或沙箱；不调整 `BookTaskScope`、既有引用与修订检查、原子写入、整书选档及恢复资格。
- 不承诺降低每次请求的实际输出消耗；不以自动提额、换模型、增轮或无限重试解决触限。本期不重做存储索引或跨文档写入的依赖判定。

## Decisions

### 1. 区分目录、搜索命中和原文页

- `book_get_context` 的通用目录和索引查询默认给有界元数据，不默认夹带一页多份正文；保留已有的 `index`、`type`、`documentId`、`offset` 和 `length`。目录／资料页可显式请求 `includeBodies`：优先按稳定顺序带上能装下的完整短资料；长资料返回可定向读的引用，不把半份资料算作完整。保留 `novelGoal` 的控制路径，不能把它当成可裁剪的目录资料。
- 定向读取返回文档 ID、类型、修订、实际原文范围及下一位置。范围用解析后文档正文的零基 UTF-16 半开区间 `[start, end)`，切页不得拆开代理对；有效非末页从实际已发送的末尾继续，而不是按模型请求的长度跳步。省略 `length` 与显式大 `length` 都受同一实际页预算。出站预算不足到不能发正文时，返回明确的未携带标记及原请求位置，提示下一步缩小批次或单独回读，而不是伪造空末页。版本变化时不得拼接不同修订的页；续读可传预期修订，变化则反馈现版并按需重新定位。
- 提供会话可发现的 `book_search_text`，按绑定作品及可选文档范围做字面搜索。命中返回有界预览、真实 ID、修订和命中位置；部分搜索与确证无命中分开，翻页沿用同一查询条件及稳定排序，不声称跨编辑持有整书快照。该工具不改变目录绑定或 `book_memory_recall` 的时序规则，也不以搜索预览登记正文锚点或全文已读。索引或命中足够时不必补读原文，只在任务需要时补读。

选择小页和字面搜索，而不是依赖主 Agent 先读大页、增加模型摘录调用或引入向量索引。此处约束的是进入模型的内容；本地全书加载的 I/O 单独测量，不将其改善计入本期保证。

### 2. 先组装结构化页，再投影当前 Run 的工具往返

在 `ActiveContext` 出站装配中增加共享策略，按结果语义识别可重读的正文、资料、搜索／召回摘录及其来源；业务控制结果和写入结果不是可重读正文。保留现有运输大小保护作兜底，而不是把通用超限错误当分页。预算计算复用本地估算，按实际序列化的可重读部分（含其结构开销）计量，并服从请求输入余量；初始实验值可从单条 2,048、最新一轮合计 6,144、此前各轮保留原文合计 8,192 个估算 token 起测，按长稿夹具调整。它们是内部结果配额，不是供应商 `maxTokens`，也不随声明大窗口无限增长。

先为调用配对、结果状态、可定位引用和当前必要控制状态留空间，再为同轮各条可重读数据分配实际额度。批次指同一回复的整组工具调用，执行仍是现有顺序。最近一轮优先给可用原文；较旧条目先去重复正文、再以结构化源引用替代，不裁成坏 JSON。不改同一往返内的 call ID、调用参数、顺序及 Messages／Chat／Responses 需要的原生协议块。历史需要进一步硬压缩时，沿现有策略移除完整旧往返，不拆孤立的调用或结果，也不重新执行被移除的写入。

当前作者消息、有效范围／目标、继续所需的待办、必要的 Skill 和仍有用的真实提交回执优先，不拿它们给大页读稿让位。首次整书 Skill 必须完整送达才记录应用，并保留真实出站的选档；必要信息仍装不下时走原有上下文不足路径，不伪造部分成功。投影不改业务返回对象、合规的 UI／历史、磁盘稿件或持久回执，也不新增原始结果留存。通用文件工具不迁移参数；有可定位结果的通用只读操作可走共享投影，写入与命令状态不能被当作读稿裁掉。

### 3. 已读进度以真实出站为准，与后续压缩解耦

当前一些读稿状态在执行工具时更新，而 `onDispatch` 又可能按原结果对象身份判断是否送达。改为让出站装配提供每个调用的实际送达描述：有没有结果、哪些字段是引用、真正发送了哪些修订和原文范围。从 `onDispatch`（请求实际交付传输层）更新本 Run 对应的已读记录及对应诊断，不根据被裁掉的内部结果补记，也不把派发当供应商接收或模型采用。

精确锚点沿用既有证据规则：只合并同文档同修订已送达的原文范围；要求完整资料的现有前提只在完整原文实际送达后满足。目录、搜索预览、裁去的后半页和未派发结果不能作为原文；已有合法的版本元数据用途不因这次投影改变。已送达的同版范围后来退为引用，不撤销本 Run 的已读事实；模型真需要短句时仍可重读。稿件更新后仍由原有修订和锚点核验约束，不引用旧版写入。真实提交明确提供的新版本继续使用既有回执语义。Messages 逐项续接可用即将实际出站的回读做临时下一步规划，最终投影视图与规划须一致；这个临时视图不更新正式已读覆盖，也不替代工具执行时的原有检查。

`book_apply_changes` 目前会检查所有现有大纲、主体和伏笔的当前已读版本，而不只是本次目标。本期保留这个前提，更新工具说明／缺项引导为显式资料页或按 ID 补读，不自动扫书。对照夹具单独统计该前提带来的读量与轮数；若仍是主成本，记录后续可把「模型实际需要的原文」和「后端的依赖与修订核验」分离，不在本期假读或暗改写入语义。

### 4. 先区分终态和派发证据，不扩大恢复

Chat 的 `parseChat` 已识别 `finish_reason: length`，但过去把它和不完整流都归为 `incomplete_stream`。在实际请求的终态诊断中增加有界的供应商停止类别：明确的 Chat 长度终态才记为显式输出触限；没有可靠终态仍是断流或协议错误；本地取消和超时保持独立。诊断分类不改变工具调度：触限的整批候选不执行、不保存半截结果。沿用仅对符合条件的 Messages 主 Agent 发起一次小步续接；无可靠范围仍不能派发写入续接。Responses 和其他通用错误不据此猜测触限。

按现有 Run／轮次／`spanId` 记录每次主 Agent 出站的总估算、实际输出上限、本轮新带入及历史保留的可重读体积、做过投影的结果数，可区分实际派发的完整、已投影和未发送结果。Skill 应用、记忆携带和结果送达都与实际出站字段一致；工具执行才记执行回执，实际落盘才记提交证据。数据通过现有白名单，记录计数、类别和安全关联标识，不记录查询词、正文、模型原生思考、工具参数或载荷。日志提供证据，不参与新授权。

### 5. 同一长稿隔离库对照，不以缩尺通过代替性能证据

先跑确定性基线和回归，同一正常篇幅十章起点，保留角色关联、中期迹象、后期首次登场、同会话确有遗留时再续办的约束。固定供应商协议、模型用途和实发预算，比较登记前的请求数量、可重读体积和总输入估算峰值；对资料写入的既有全读路径单独记录翻页次数。强制覆盖同一批多个读、历史累积、修订改变、无派发和首次整书 Skill。业务断言读回正文、大纲、资料、修订及提交回执，未授权内容保持不变。若只降低峰值却造成重复读或业务退化，不作性能验收结论。

实盘同协议长稿对照为另行选择的验证：隔离快照及正常应用入口，主 Agent 自选工具，不改产品预算、不无限发「继续」。记录成本与实际 usage 仅限供应商确实提供的值。没有实盘或仅有单次样本时，不宣称真实网关的触限率已经改善。旧缩尺案例继续验证原业务链路，不用作同负载性能对照。

## Risks / Trade-offs

- 软配额太小，索引和读稿翻页增加 → 先比较同起点的出站体积和总轮数，保留显式资料页；不以降低单次体积掩盖循环。
- 批次裁剪造成漏页或把摘要当成已读 → 按实际送出范围生成续页，保留修订，分别测试已准备、已派发和已淘汰三种状态。
- 裁剪触及写入或首次 Skill 交接 → 明确受保护的字段和完整送达条件，协议信息原样保留；不能安全装入时沿用原失败边界，不损坏真实回执。
- 主 Agent 仍在登记前查稿或构造大参数时输出触限 → 一期结果要能区分输入构成和输出终态，保留现有有范围的小步续接与无范围的停止行为。后续通用委派不是本期的兜底。

## Migration Plan

无需数据迁移或新用户设置。先记录未改实现的对照样本，再用书稿分页、共享投影和诊断完成回归。若回退，仅回退工具与装配逻辑，不改磁盘稿件、Session、现有回执或诊断留存。性能数值以同负载对照为准，不向旧记录补写无法观察的诊断。

## Open Questions

- 根据长稿夹具校准软配额，确认省略长度的常见读足够支撑定位与补丁，又不会迫使普通任务多轮翻页。
- 若既有资料全读前提仍主导开销，以对照数据为依据另立依赖范围优化；不在本期只为降低指标减少业务核验。
