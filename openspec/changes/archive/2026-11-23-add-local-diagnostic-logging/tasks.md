## 实施验证

- `npm run typecheck` 通过；`npm test` 44 项通过；Windows `npm run test:e2e` 15 项通过；OpenSpec 严格校验通过。
- 从桌面夹具实际写出的两份 JSONL 独立对照：不完整工具 JSON 被拒绝、没有执行，但错误结果进入下一请求；一次已落盘的主体变更漏收通知，随后从序号缺口触发重读、界面显示同一修订；整书失败后换了启动实例，通过同一检查点引用关联，跳过已完成的第一章并完成第二章。

- 复核后补测四个边界：缺字段或与实发通知不匹配的回执不落盘；流提前失败与坏工具批次保留候选拒绝轨迹、不伪称执行；单个日文件拒写不丢弃其他文件的待写事件；同日清理失败最多重试两次、间隔至少一分钟。
