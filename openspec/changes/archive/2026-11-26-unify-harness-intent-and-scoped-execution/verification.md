## 如何重跑真实验收

在本地测试进程的安全环境设置 `FW_LIVE_API_KEY`、`FW_LIVE_BASE_URL`、`FW_LIVE_MODEL` 和 `FW_LIVE_PROTOCOL`（`chat`、`responses` 或 `messages`），不要把密钥写入仓库或贴进对话。可替代地指定隔离实例有权解密的 `FW_LIVE_PROFILE_FILE` 和 `FW_LIVE_PROFILE_NAME`。运行 `npm run build` 后执行 `npx playwright test yellow-lantern-live --workers=1 --output=test-results/yellow-lantern-recheck`。每个真实 Run 默认等待 20 分钟；更长的用例可用 `FW_LIVE_RUN_WAIT_MINUTES`（正整数分钟）调整，仅影响验收脚本。样例自动在隔离测试根以内清除同名小说并重建；写作、读回与回执仍来自真实业务链。
